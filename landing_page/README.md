## Local Preview
Run `run_landing_page.bat` from the repository root, or run:
```bash
npx serve -l tcp://127.0.0.1:8088 -l tcp://[::1]:8088 --no-port-switching -n landing_page
```
Then open `http://localhost:8088`.
